This repo contains the openadmet2025 challenge v7 files using tabpfn to fit the molecular properties.
I include all the different versions used.

Will work on updating documentation as to the different versions and what each file contains.

Key files are pequqa_*.py which have the iterations used on the model.

The pipeline_config.json specifies how the job will run.

The various CSV files are either input to the training set from OpenADMET, auxiliary files used to train related 
parameters from external data sets, and variations on the training set with some variables log or pk scaled.

There is also the challenge.csv which is the challenge set for OpenADMET 2025.
